# Birthday Surprise

A mobile-first, static birthday experience ready to deploy on Netlify.

## Add your media

1. Put your background song at `music/our-song.mp3`.
2. Add `videos/01-opener.mp4`.
3. Add fifteen clips from `videos/02-memory-1.mp4` through `videos/16-memory-15.mp4`.
4. Add `videos/17-final-surprise.mp4`.
5. Optionally add `images/opener-poster.jpg` and `images/final-poster.jpg`.

The final surprise unlocks only after all fifteen memories have reached their end. Watch progress persists locally in the browser. Deploy the folder directly to Netlify; `netlify.toml` is already included.
